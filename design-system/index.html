Lumière by Les Fleurs de la Nuit
Darkroom

The design system for a night-photography lighting editor. Graphite neutrals with a hair of warmth stay out of the photo's way; one safelight red-orange marks what is active. Compact density, every touch target at least 44 px. Material token roles, MUI component catalogue. Source of truth: styles.css. Turn on Dev Mode to inspect a component; Copy as prompt implements it in any language.

Palette

MUI palette roles, each main / light / dark / contrastText, plus a container pair for quiet emphasis. Neutrals are graphite at OKLCH chroma 0.004, hue 55: neutral enough to judge a photo against, warm enough not to feel clinical. Ratios below are WCAG contrast, computed from the hex values.

Typography

Manrope for display (h1–h6), IBM Plex Sans for text, IBM Plex Mono for every number a photographer reads (percentages, sizes, Kelvin). ~1.2 modular scale for a compact UI; tracking tightens as size grows.

Spacing

One compact scale on a 4 px unit (spacing(n) = n × 4px). Touch targets stay ≥ --target (44 px) even where visuals are 32–40 px: the hit area is padded, not the paint.

Shape

Tight, square-ish corners. Controls use --r-md (8); sheets and cards --r-lg (12); only dots, avatars and switches are round.

Shadows

Flat, with hairlines. Depth comes first from the surface ladder (sunken → bg → paper → raised → overlay), then from four shadow levels. MUI's 25 shadow steps map onto them: 0 → elev-0 · 1–2 → elev-1 · 3–8 → elev-2 · 9–24 → elev-3.

Transitions

MUI durations and easings. Sheets and panels use --ease (fast out, soft landing, no overshoot). Everything collapses to instant when the device asks for reduced motion.

Breakpoints · z-index

Phone-first. Breakpoints are documented values (CSS variables can't be used inside media queries); z-index follows MUI's stacking order.

Icons

Inline SVG sprite in the Material-outlined style, themed by --icon-size (20) and --icon-stroke (1.75). Includes the app's own glyphs: light, blur, mask, radial and linear gradients, subject, object, brush, invert, solo. Never emoji.
